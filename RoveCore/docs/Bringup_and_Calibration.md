# P-TIWARI bring-up and firmware contract

The hardware project does not include a validated application firmware image. Firmware is required to coordinate the integrated devices. Perform first assembly on a current-limited bench supply with no motors/servos connected.

1. Inspect orientation of the ESP32, USB bridge, motor driver, inductors, polarized capacitors, reverse FETs and the VEML7700-TT. Check for supply shorts before applying power.
2. Leave the servo source-select shunt removed. Apply external regulated 5 V to J4 with a conservative current limit. Measure LOGIC5 and 3V3, EN delay and sensor supply. Confirm BOOT high and GPIO12 low at reset. Do not treat a power LED as proof all rails are correct.
3. Connect USB. Verify enumeration, serial loop, reset and automatic download. Test USB plugged/unplugged with external power present and check reverse current. Configure CP2102N descriptors consistently with actual USB power behavior. Measure inrush and suspend current before claiming USB compliance.
4. Flash a minimal program with all motor controls LOW and servo OE HIGH. Keep Wi-Fi off during initial current checks. Confirm the radio's 3.3 V supply remains in specification during maximum TX bursts.
5. Run a 100 kHz I²C scan. Expected addresses: 0x10, 0x1C, 0x20, 0x29, 0x40 (plus default 0x70 all-call), 0x48, 0x6A, 0x76. Confirm identity registers and plausible raw values, not only ACK responses.
6. Initialize MCP23017 safely: preload OLATA=0xE0 (RGB outputs high/off, motor sleep low), OLATB=0x00; initially configure GPA0/5/6/7 and GPB7 as outputs, the rest inputs. GPA7/GPB7 are **output only** in the current MCP23017 datasheet. GPA2 remains input to release XSHUT; to assert XSHUT, first write its latch LOW and then change that pin to output. Return it to input to release. Never drive HIGH into an unpowered sensor.
7. Configure the ToF with the ST driver and 2V8 I/O mode. Verify interrupt behavior, offsets and cover-glass crosstalk if an enclosure window is added. Use the manufacturer's offset/crosstalk calibration flow and preserve the optical opening during assembly.
8. Set IMU data-ready INT1 as required, initially test at low output data rate. Record stationary gyro bias, six-face accelerometer calibration, device mounting axes and thermal drift. Use direct GPIO32 interrupts, FIFO and bounded sampling latency for balancing control.
9. Calibrate compass in the final chassis using hard/soft-iron fitting. Compare motor-off and motor-loaded measurements, several headings and current levels. Use nylon/nonmagnetic mounting near the compass. Static calibration cannot reliably remove time-varying motor-current fields; prefer motor-off compass samples or an external remote compass when necessary.
10. Place BME280 in forced-measurement mode for low self-heating. Compare ambient readings with a reference at several board loads and enclosure conditions; store a characterized offset if justified. Keep flux/cleaning contamination out of its port.
11. Apply 6.4–8.4 V battery input from a bench source with external cell protection substituted by current limiting for bench use. Verify BAT5 and the unloaded servo buck before fitting the correct JP1 shunt. Test programmed servo pulses on an oscilloscope before connecting an actuator. A battery supply is required for the BAT5-powered signal buffers even with external servo power.
12. Program PCA9685 with outputs disabled, totem-pole outputs, normal polarity, internal oscillator and approximately 50 Hz. With a nominal 25 MHz oscillator a prescale around 121 gives approximately 50 Hz. Calibrate the actual oscillator. At 50 Hz one count is approximately 4.88 µs; start with about 205–410 counts for 1–2 ms pulses and narrow further for the actual servo. Then enable GPIO15 LOW. Keep enable HIGH at reset, fault or watchdog timeout. Servos have different mechanical limits; pulses are not universal angle commands.
13. With motor sleep still LOW, apply separate VM from a current-limited, sink-capable source. Verify shunt resistance and no unexpected output voltage. Set one bridge at a time; use approximately 20 kHz direct ESP32 PWM where appropriate. Per bridge, 00 is coast, 01/10 drive direction, and 11 brake. Determine wheel sign conventions. Raise sleep only after control outputs are configured. Verify actual current regulation, fault behavior, stall temperature and braking VM overshoot.
14. Test each quadrature input with a signal generator and then an encoder. Confirm PCNT direction, count mode (x1/x2/x4) and overflow handling. GPIO34/35/36/39 are input-only. Do not attempt to configure their nonexistent internal pullups.
15. Validate ADS1115 inputs against a known voltage with an appropriate PGA setting. Inputs remain bounded by the supply regardless of selected full-scale range. Test channel-to-channel settling. Its 860 samples/s figure is aggregate, not 860 per channel.
16. Stress logic, servo and motor domains individually and together, measuring ground bounce, rail droop, regulator/inductor/FET temperatures, encoder errors and sensor noise. Derate current limits based on results. Keep heaters, batteries, magnetic screws and motors away from the compass and BME280.

For production firmware, use watchdogs and a motor command timeout; turn off motor sleep and disable servo outputs on lost control link. Reserve two OTA slots in 8 MB flash, authenticate updates and commands, and test power-loss recovery. Hardware timers, interrupts, PWM and network protocols are firmware capabilities of the selected ESP32; the PCB does not implement these algorithms by itself.

J1 supports UART programming and logging. Boot recovery is hold BOOT, tap RESET, start upload, then release BOOT. JTAG is not simultaneously usable with the default motor/ultrasonic/servo assignments on GPIO12–15; using it requires disabling those functions and deliberate access to GPIO12. No native USB debugger is claimed.
