# Local symbol and footprint provenance

RoveFlight.kicad_sym contains datasheet-derived BMI270, BMP390, TPS3431, SN74LVC1G74, DMP2008UFG and TSOP75438TT symbols. TPS3808G01 is expanded from the KiCad TPS3808DBV symbol with pin 1 corrected from output to open collector, matching TI's open-drain reset output. This correction is electrical metadata, not a changed pinout. DMP2008UFG drain leads 5–8 share one electrical terminal and the upstream footprint's combined drain land numbered 5; source leads 1–3 remain separate terminals.

BMP390_LGA10 uses Bosch's top-view pin numbering and the nominal land dimensions recommended in datasheet Figure 26. TSOP75438TT uses Vishay's component-side 0.8 x 1.8 mm pads at 1.27 mm pitch; its body courtyard is offset from the single pad row. MotorPads and BatteryPads are original solder-wire interfaces, and ProbePad is a PCB test pad. These original assets follow the project licence.

Standard embedded symbols and referenced footprints/models originate from the KiCad community libraries. Their licence and exception are included in KiCad-LICENSE.md. Upstream repositories: https://gitlab.com/kicad/libraries/kicad-symbols and https://gitlab.com/kicad/libraries/kicad-footprints. Any local copies made during layout finishing retain that licence and are documented in the construction scripts. The project does not bundle third-party 3D model collections; install the KiCad 10 model package to resolve model paths.

ESP32-S3-WROOM-1_Overhang preserves the upstream module pad numbering, copper keepout, courtyard and model while moving off-board silkscreen to Fab. Footprint_Variants.json records 70 additional per-reference variants created by the final silkscreen pass; obscured silkscreen graphics were moved to Fab, with copper, pad numbering, courtyards and models preserved. These are explicit library assets, so native library-consistency checks remain enabled. The schematic symbols retain their upstream identities and default definitions; instance Footprint fields select the local land patterns.
