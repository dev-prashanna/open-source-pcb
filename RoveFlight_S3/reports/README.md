# Validation evidence

ERC.json, DRC.json, Connectivity_Audit.json, Physical_Audit.json and Assembly_Audit.json describe the released native design. Regenerate them with scripts/release.py. DRC includes schematic parity and refilled-zone connectivity.

Other JSON files are construction-operation logs retained for engineering history. They do not supersede the final reports. Intermediate DRC, autorouter sessions and placement backups are excluded from version control.
